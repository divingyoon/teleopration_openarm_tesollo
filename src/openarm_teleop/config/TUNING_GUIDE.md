# Leader Arm Friction Tuning Guide

## 개요

Leader arm은 순수 토크 모드로 동작합니다. 사람이 팔을 잡고 움직일 때 **무중력처럼 느껴지도록** 중력보상 + 마찰보상 토크를 모터에 명령합니다.

```
tau_cmd = tau_gravity + tau_friction × 0.3 + tau_coriolis × 0.1
```

> **Note:** 코드에서 마찰 보상은 계산값의 30%만 적용됩니다 (`friction * 0.3`).
> yaml의 Fc, Fv, Fo는 실제 적용 토크의 **3배 값**으로 설정해야 의도한 크기가 나옵니다.

---

## 마찰 보상 모델

```
tau_friction = Fc × tanh(0.1 × k × dq) + Fv × dq + Fo
```

> `0.1`은 코드 내 `coef_tmp`로 하드코딩된 스케일입니다.
> yaml의 `k`를 100으로 설정하면 실제 전환 날카로움은 `0.1 × 100 = 10`이 됩니다.

---

## 파라미터별 의미 및 조정 효과

### Fc — Coulomb 마찰 크기 [Nm]

정적 마찰(쿨롱 마찰)의 크기. 모터가 처음 움직이기 시작할 때 극복해야 하는 고착력에 해당합니다.

```
Fc 증가 → 저속에서 더 강하게 밀어주는 힘. 정지 상태 처짐 방지
Fc 감소 → 저속에서 모터가 끊기거나 관절이 중력에 처지는 느낌
```

**튜닝 기준:** 팔을 아주 천천히 움직일 때 "뭔가 걸리는 느낌"이 있으면 Fc를 늘리고,
이미 충분히 보정되는데 저속에서 오히려 튀는 느낌이 나면 Fc를 줄입니다.

---

### k — tanh 전환 날카로움 (무차원)

마찰 곡선이 얼마나 빠르게 포화되는지 결정합니다. 실제 적용값은 `0.1 × k`.

```
k 크게 (> 100) → 날카로운 전환. 속도 0에서만 마찰이 집중되고, 조금만 움직여도 거의 사라짐
                 → 쿨롱 마찰 특성 (딸깍하고 빠져나오는 느낌)
                 → 관절이 가볍고 자유롭게 느껴짐

k 작게 (< 20)  → 완만한 전환. 속도가 붙어도 마찰이 계속 증가
                 → 점성 마찰(viscous) 특성
                 → 관절이 움직일수록 저항이 커지는 댐퍼 느낌
```

**k값 비교 (dq = 0.2 rad/s 기준):**

| k | tanh(0.1k × 0.2) | Fc 중 적용 비율 | 체감 |
|---|---|---|---|
| 4 | tanh(0.08) ≈ 0.08 | **8%** | 거의 없음 |
| 7.9 | tanh(0.16) ≈ 0.16 | **16%** | 댐퍼처럼 느껴짐 |
| 28 | tanh(0.56) ≈ 0.51 | **51%** | 중간 |
| 130 | tanh(2.6) ≈ 0.99 | **99%** | 거의 포화 |
| 242 | tanh(4.8) ≈ 1.00 | **100%** | 완전 포화 |

**튜닝 기준:** 관절이 움직일수록 무거워지는 느낌이면 → k를 100 이상으로 올립니다.

---

### Fv — 점성 마찰 계수 [Nm·s/rad]

속도에 비례하는 마찰. `Fv × dq`가 추가됩니다.

```
Fv 증가 → 빠르게 움직일수록 더 큰 저항. 팔이 끈적하게 느껴짐
Fv 감소 → 빠른 움직임이 가벼워짐. 단, 진동/오버슈트 가능성 증가
```

**튜닝 기준:** 팔을 빠르게 휘두를 때 과도하게 무거우면 Fv 감소.
팔이 떨리거나 덜컥거리면 Fv 증가.

---

### Fo — 마찰 오프셋 / 바이어스 [Nm]

속도에 무관한 상수 토크. 중력보상 잔여 오차 또는 물리적 마찰 비대칭성을 잡습니다.

```
Fo > 0 → 관절이 양의 방향으로 계속 밀림
Fo < 0 → 관절이 음의 방향으로 계속 밀림
Fo = 0 → 정지 상태에서 방향성 없음 (이상적)
```

**튜닝 기준:** 팔을 놓았을 때 특정 방향으로 천천히 흘러가면, Fo를 반대 부호 방향으로 ±0.01 씩 조정합니다.

## Joint 7 튜닝 권장 절차

### 1단계: k 값을 손목 관절 수준으로 올리기

```yaml
# 현재 (비정상적으로 낮음)
k: [..., 7.888, ...]

# 권장 시작값
k: [..., 100.0, ...]
# J5(152), J6(242)과 비슷한 수준으로. 100 → 130 → 150 순으로 올리며 테스트
```

### 2단계: Fo로 정지 편향 제거

k 조정 후 팔을 중간 자세에서 놓고 흘러가는 방향을 확인합니다.

```yaml
# 현재: Fo[6] = -0.059
# 양의 방향으로 흘리면: Fo를 더 음수로 (예: -0.07)
# 음의 방향으로 흘리면: Fo를 0에 가깝게 (예: -0.03)
# ±0.01 단위로 조정
```

### 3단계: Fc 재확인

k를 올린 후 저속에서 여전히 끊기는 느낌이 있으면 Fc를 J5, J6 수준으로 낮춥니다.

```yaml
# 현재: Fc[6] = 0.172 (J5=0.050, J6=0.083 보다 2배 이상 큼)
# k 올린 후에도 끈적함이 남으면: 0.172 → 0.10 수준으로 낮춤
```

## Tesollo 핸드 무게를 고려한 Right Arm 튜닝

### 물리 구성

```
Right LEADER arm  → 표준 그리퍼 (0.35 kg)  ← 사람이 잡는 팔, 조작감에만 영향
Right FOLLOWER arm → Tesollo DG5F (1.685 kg) ← 로봇 실행 팔
```

Tesollo 핸드는 FOLLOWER에 달려 있으므로 **leader의 중력보상은 0.35 kg 기준으로 이미 올바르게 설정**되어 있습니다.

### Leader 조작감 튜닝 (right_arm/leader.yaml)

Left leader와 Right leader는 같은 0.35 kg 그리퍼를 사용하지만 **개체별 물리 마찰 특성이 다를 수 있습니다.**
Left leader의 조작감을 기준으로 right leader를 맞춥니다.

```
1. 왼팔을 잡고 천천히 각 관절을 움직여 기준 느낌 파악
2. 오른팔을 잡고 다른 느낌이 나는 관절 확인
3. 해당 관절의 Fo 먼저 조정 (±0.01 단위)
4. 그래도 다르면 Fc, k 순으로 조정
```

### Follower 추종 성능 튜닝 (right_arm/follower.yaml)

Tesollo 핸드(1.685 kg)는 표준 그리퍼(0.35 kg)의 **4.8배** 무겁습니다.
관성이 크면 PD 추종이 느려지고 오버슈트가 생길 수 있습니다.

```yaml
# 조정 방향:
# 손목 관절 (J5~J7): 관성 증가 영향이 크므로 우선 조정
#   - 추종이 느림/뒤처짐 → Kp 증가
#   - 진동/오버슈트   → Kp 감소 또는 Kd 증가
#   - 댐핑 부족       → Kd 증가
# 어깨/팔꿈치 (J1~J4): 팔 자체 관성이 지배적, 소폭 조정
```

## 빠른 증상 대응표

| 증상 | 파라미터 | 조치 |
|---|---|---|
| 팔을 놓으면 특정 방향으로 흘러감 | Fo | 반대 부호 방향 ±0.01 |
| 저속에서 끊기거나 처짐 | Fc 작음 | Fc 증가 |
| 움직일수록 점점 무거워짐 | k 작음 | k를 100 이상으로 증가 |
| 빠른 움직임이 과도하게 무거움 | Fv 큼 | Fv 감소 |
| 빠른 움직임 후 진동/떨림 | Fv 작음 | Fv 증가 |
| Follower가 leader를 못 따라감 | Kp 부족 | follower.yaml Kp 증가 |
| Follower가 진동함 | Kd 부족 | follower.yaml Kd 증가 |
| Follower 오버슈트 | Kp 과다 | follower.yaml Kp 감소 |
